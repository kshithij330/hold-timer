Contact

This is a small side project, so the fastest route depends on what you are bringing: a bug, an idea, or a question.

Where to write

Open an issue github.com/kshithij330/hold-timer/issues Best for bugs and feature requests — the discussion stays public and searchable. Email kshithij330@users.noreply.github.com For anything that does not belong in a public thread. GitHub profile github.com/kshithij330 See what else is being built.

What to include

A report without these details usually means a round trip of questions before anything can happen:

  • Browser and OS — for example Safari on iOS 18, or Chrome on Windows 11.
  • What you did — hold, release, stop; which key or tap.
  • What you expected and what actually happened.
  • Your times, if they matter — the list is stored locally, so it is not visible from the outside.

About replies

This is maintained in spare time, so expect a few days rather than a few minutes. Issues that include a clear reproduction usually get answered first.

Security concerns should go by email rather than into a public issue.
