# Hold Timer

A minimal speed-timer page, styled like a plain timer app (no cubing references).

**How it works**

- Hold `space` — the display flashes `00`.
- Release `space` — the timer starts.
- Press any key — the timer stops and the solve is recorded.

The left panel keeps every recorded time and shows the average of 5 (trimmed), the average of 12 (trimmed), and the best time. Times are saved in `localStorage`, so they survive a reload.

Touch: press and hold anywhere on the timer area, release to start, tap to stop.

Open `index.html` directly, or serve it with GitHub Pages.
